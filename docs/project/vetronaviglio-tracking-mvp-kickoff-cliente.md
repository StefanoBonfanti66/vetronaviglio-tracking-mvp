# Kickoff Cliente — Vetronaviglio Tracking MVP

- **Data:** 21/07/2026
- **Progetto:** MVP Dashboard Tracking Spedizioni Multi-corriere
- **Preventivo:** 2026-001 — €10.200

---

## Obiettivi condivisi

Insieme a Vetronaviglio, ci proponiamo di:

1. **Centralizzare il tracking** di tutte le spedizioni in un'unica dashboard web
2. **Integrare FedEx API** per il tracking automatico delle spedizioni verso e dall'estero
3. **Gestire gli altri corrieri** manualmente o con import CSV, senza dover cambiare i vostri processi attuali
4. **Costruire un sistema estensibile** che può crescere con voi — domani potrete aggiungere nuovi corrieri senza riscrivere nulla

---

## Cosa è incluso nel progetto

- Dashboard web con vista principale, filtri per stato e corriere, ricerca e dettaglio spedizione
- Integrazione diretta con FedEx Track API
- Inserimento manuale e import CSV per corrieri senza API
- Modello dati unico che normalizza gli stati di tracking
- Deploy su Vercel con documentazione operativa
- 30 giorni di garanzia post go-live

## Cosa è esplicitamente fuori scope

- Integrazione API con corrieri diversi da FedEx (futura estensione)
- Alerting automatico via email/SMS (futura estensione)
- Reporting e analytics avanzati (futura estensione)
- Integrazione con eventuali sistemi interni (ERP/gestionale)
- Mobile app
- Hosting e licenze API (a vostro carico)
